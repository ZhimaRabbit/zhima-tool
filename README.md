# 🛠️ NetScanner - 极简局域网探测工具

> 本项目仅供计算机网络基础学习与内部测试使用，请勿用于非法扫描。

## 📄 项目简介
**NetScanner** 是一个基于 Python 原生 `socket` 和 `threading` 库开发的轻量级网络扫描工具。
**无需安装任何第三方依赖**，即可在标准 Python 环境中快速发现局域网内的在线设备。

## ✨ 核心功能
- **零依赖**：纯 Python 内置库，复制即用。
- **多线程并发**：采用多线程扫描，速度极快。
- **超时控制**：设定了 0.3 秒的超时，防止扫描卡死。
